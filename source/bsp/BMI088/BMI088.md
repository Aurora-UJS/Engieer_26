# BMI088 传感器驱动说明

## 概述
BMI088 是一款6轴惯性测量单元(IMU)，包含3轴加速度计和3轴陀螺仪。本驱动支持通过SPI接口与BMI088通信。

## 硬件连接
- 使用SPI2接口 (hspi2)
- 加速度计片选引脚: ACC_CS_Pin
- 陀螺仪片选引脚: GYRO_CS_Pin
- 需要TIM3用于延时(PWM模式)

## 初始化流程

### 1. 整体初始化
调用 `BMI088_init()` 函数完成以下操作：
1. 初始化GPIO和SPI接口
2. 初始化加速度计
3. 初始化陀螺仪

```c
uint8_t error = BMI088_init();
if(error != BMI088_NO_ERROR) {
    // 错误处理
}
```

### 2. 加速度计初始化
`bmi088_accel_init()` 函数执行以下步骤：
1. 检查通信(读取芯片ID)
2. 软件复位
3. 配置以下寄存器：
   - 电源控制(ACC_PWR_CTRL)
   - 电源模式(ACC_PWR_CONF) 
   - 带宽和输出数据速率(ACC_CONF)
   - 量程(ACC_RANGE)
   - 中断配置(INT1_IO_CTRL, INT_MAP_DATA)

### 3. 陀螺仪初始化  
`bmi088_gyro_init()` 函数执行以下步骤：
1. 检查通信(读取芯片ID)
2. 软件复位
3. 配置以下寄存器：
   - 量程(GYRO_RANGE)
   - 带宽(GYRO_BANDWIDTH)
   - 电源模式(GYRO_LPM1)
   - 数据就绪信号(GYRO_CTRL)
   - 中断配置(GYRO_INT3_INT4_IO_CONF, GYRO_INT3_INT4_IO_MAP)

## API说明

### 数据读取
```c
void BMI088_read(float gyro[3], float accel[3], float *temperate);
```
- 参数：
  - gyro: 陀螺仪数据(rad/s)，数组顺序[x,y,z]
  - accel: 加速度数据(m/s²)，数组顺序[x,y,z] 
  - temperate: 温度数据(℃)指针
- 注意：数据已根据配置的量程进行转换

### 寄存器读写宏
驱动提供以下SPI读写宏：
```c
// 加速度计
BMI088_accel_write_single_reg(reg, data)
BMI088_accel_read_single_reg(reg, data)
BMI088_accel_read_muli_reg(reg, data, len)

// 陀螺仪  
BMI088_gyro_write_single_reg(reg, data)
BMI088_gyro_read_single_reg(reg, data)
BMI088_gyro_read_muli_reg(reg, data, len)
```

## 使用示例

```c
float gyro[3], accel[3], temp;

// 初始化
if(BMI088_init() != BMI088_NO_ERROR) {
    // 错误处理
}

// 循环读取数据
while(1) {
    BMI088_read(gyro, accel, &temp);
    // 使用数据...
    HAL_Delay(10);
}
```

## 注意事项
1. 严格的时序要求：
   - 寄存器写入后需要延迟 `BMI088_COM_WAIT_SENSOR_TIME` (us级)
   - 复位后需要延迟 `BMI088_LONG_DELAY_TIME` (ms级)

2. 量程配置：
   - 加速度计量程: 默认3G (`BMI088_ACCEL_3G_SEN`)
   - 陀螺仪量程: 默认2000dps (`BMI088_GYRO_2000_SEN`)

3. 错误处理：
   - 初始化函数返回错误代码，需检查处理
   - 常见错误：
     - `BMI088_NO_SENSOR`: 通信失败
     - `BMI088_ACC_PWR_CTRL_ERROR`: 加速度计电源控制错误
     - `BMI088_GYRO_RANGE_ERROR`: 陀螺仪量程配置错误

4. 硬件依赖：
   - 需要实现 `BMI088_delay_us()` 和 `BMI088_delay_ms()`
   - 需要配置正确的SPI接口和片选引脚
