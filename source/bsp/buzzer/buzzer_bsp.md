# 蜂鸣器驱动模块说明文档

## 模块概述

本模块实现了蜂鸣器的初始化、开关控制功能，基于STM32的TIM定时器外设实现PWM波形输出，用于驱动蜂鸣器发声。通过调整PWM的频率和占空比，可以控制蜂鸣器发出不同频率的声音。

---

## 文件结构

- **buzzer_bsp.c**：蜂鸣器驱动的核心实现文件。
- **buzzer_bsp.h**：蜂鸣器驱动的头文件，包含函数声明和相关宏定义。
- **tim.h**：定时器外设的配置头文件，提供定时器相关的初始化和操作接口。

---

## 功能描述

### 1. 蜂鸣器初始化
函数原型：
```c
void buzzer_init(void);
```
功能：

初始化蜂鸣器，启动TIM12定时器的PWM通道2（TIM_CHANNEL_2）。
配置定时器为PWM输出模式。
### 2. 蜂鸣器开启
函数原型：

```c
void buzzer_on(uint32_t frequency, float duty_cycle);
```
功能：

- 设置蜂鸣器的发声频率和占空比。

参数说明：
- frequency：频率值（单位：Hz），范围为16~1000000 Hz。
- duty_cycle：占空比（范围：0~1）。

内部逻辑：
- 根据输入频率计算自动重装载值（ARR）。
- 根据占空比计算捕获/比较寄存器值（CCR）。
- 更新TIM12定时器的ARR和CCR寄存器值。

### 3. 蜂鸣器关闭
函数原型：

```c
void buzzer_off(void);
```
功能：

关闭蜂鸣器发声。
实现方式：调用buzzer_on(16, 0)，将频率设置为最低值（16 Hz），占空比设置为0。
### 使用方法
1. 初始化
在系统初始化阶段调用buzzer_init()函数，完成蜂鸣器硬件资源的初始化。

2. 开启蜂鸣器
调用buzzer_on(frequency, duty_cycle)函数，传入所需的频率和占空比参数。例如：

```c
buzzer_on(1000, 0.5); // 发出1000 Hz频率，50%占空比的声音
```
3. 关闭蜂鸣器
调用buzzer_off()函数，停止蜂鸣器发声。

注意事项

- 频率范围：蜂鸣器支持的频率范围为16 Hz到1000000 Hz，超出此范围的值会被限制到边界值。
- 占空比范围：占空比应为0到1之间的浮点数，超出范围可能导致不可预期的行为。
- 硬件依赖：本模块依赖TIM12定时器的PWM通道2，确保硬件配置与代码一致。
### 示例代码
以下是一个完整的使用示例：

```c
#include "buzzer_bsp.h"

int main(void)
{
    // 初始化蜂鸣器
    buzzer_init();

    while (1)
    {
        // 发出1000 Hz频率，50%占空比的声音
        buzzer_on(1000, 0.5);
        HAL_Delay(1000); // 延时1秒

        // 关闭蜂鸣器
        buzzer_off();
        HAL_Delay(1000); // 延时1秒
    }
}
```
总结:

本模块提供了简单易用的API接口，开发者可以通过调用buzzer_init()、buzzer_on()和buzzer_off()函数轻松实现蜂鸣器的控制。同时，模块对输入参数进行了有效范围检查，确保系统的稳定性和安全性。
