# 键盘模块说明

## 功能概述
本模块定义了键盘和鼠标输入的数据结构，用于处理来自PC的输入控制信号。

## 数据结构
在`keyBoard.h`中定义了`keyboard_t`结构体：

```c
typedef struct {
    int16_t mouse_x;        // 鼠标X坐标
    int16_t mouse_y;        // 鼠标Y坐标 
    int16_t mouse_z;        // 鼠标Z坐标(滚轮)
    int8_t left_button_down;  // 左键按下状态
    int8_t right_button_down; // 右键按下状态
    union {
        uint16_t key_code;   // 按键状态组合值
        struct {
          uint16_t W : 1;    // W键
          uint16_t S : 1;    // S键
          uint16_t A : 1;    // A键
          uint16_t D : 1;    // D键
          uint16_t SHIFT : 1; // SHIFT键
          uint16_t CTRL : 1;  // CTRL键
          uint16_t Q : 1;     // Q键
          uint16_t E : 1;     // E键
          uint16_t R : 1;     // R键
          uint16_t F : 1;     // F键
          uint16_t G : 1;     // G键
          uint16_t Z : 1;     // Z键
          uint16_t X : 1;     // X键
          uint16_t C : 1;     // C键
          uint16_t V : 1;     // V键
          uint16_t B : 1;     // B键
        } bit;
    } key_code;
    uint16_t reserved;      // 保留位
} keyboard_t;
```

## 按键位域说明
- 每个按键使用1位表示状态(0:未按下, 1:按下)
- 支持的按键：
  - 方向控制：W(前), S(后), A(左), D(右)
  - 功能键：SHIFT, CTRL
  - 其他按键：Q, E, R, F, G, Z, X, C, V, B

## 使用示例
```c
keyboard_t kb_input;

// 检查W键是否按下
if(kb_input.key_code.bit.W) {
    // 处理前进逻辑
}

// 检查鼠标左键
if(kb_input.left_button_down) {
    // 处理鼠标左键点击
}
