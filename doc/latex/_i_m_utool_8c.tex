PID温度控制函数。 

该函数实现了一个简单的\+PID控制器，用于调节\+IMU模块的温度至目标值（\+DES\+\_\+\+TEMP）。 控制器通过计算当前温度与目标温度之间的误差，调整\+PWM输出以控制加热功率。

控制公式为： out = KP \texorpdfstring{$\ast$}{*} err + KI \texorpdfstring{$\ast$}{*} (err + err\+\_\+l + err\+\_\+ll) + KD \texorpdfstring{$\ast$}{*} (err -\/ err\+\_\+l) 其中：
\begin{DoxyItemize}
\item err\+: 当前温度误差。
\item err\+\_\+l\+: 上一次温度误差。
\item err\+\_\+ll\+: 上上次温度误差。
\item KP, KI, KD\+: PID控制器的比例、积分、微分系数。
\end{DoxyItemize}

输出值被限制在 \mbox{[}0, MAX\+\_\+\+OUT\mbox{]} 范围内，并通过定时器通道（htim3.\+Instance-\/\texorpdfstring{$>$}{>}CCR4）设置\+PWM占空比。
