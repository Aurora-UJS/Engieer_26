功率控制模块用于控制设备的功率输出，包括设备的率调节操作。该模块提供了一系列的\+API接口，用户可以通过调用这些接口来实现对设备的控制。但当前主要是进行电机的功率控制。\hypertarget{md_source_2module_2control_2_power_control_2_power_control_autotoc_md38}{}\doxysection{\texorpdfstring{2. 接口说明}{2. 接口说明}}\label{md_source_2module_2control_2_power_control_2_power_control_autotoc_md38}

参数说明：


\begin{DoxyItemize}
\item {\ttfamily buffer\+\_\+ptr}：功率控制缓冲区指针，用于存储功率控制数据。
\item {\ttfamily cap\+\_\+ptr}：功率控制电容指针，用于存储功率控制电容数据。
\item {\ttfamily max\+\_\+power}：功率控制最大功率，用于限制功率控制的最大输出功率。
\item {\ttfamily pid\+\_\+params}：\+PID参数结构体指针，用于设置功率控制的\+PID参数。
\item {\ttfamily hook}：回调函数指针，用于在功率控制过程中调用主要设备参数。

函数功能：计算单个电机的理论功率消耗。

参数说明：


\begin{DoxyItemize}
\item {\ttfamily pid\+\_\+output}：\+PID输出值，用于计算功率消耗。
\item {\ttfamily speed\+\_\+rpm}：电机转速，用于计算功率消耗。
\item {\ttfamily params}：电机功率参数结构体指针，用于设置电机功率参数。
\end{DoxyItemize}

返回值：


\begin{DoxyItemize}
