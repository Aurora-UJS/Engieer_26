一阶低通滤波器计算函数。 

此函数根据当前输入值和滤波器的平滑因子 alpha 计算滤波后的输出值。 滤波公式为： output = (1.\+0 -\/ alpha) \texorpdfstring{$\ast$}{*} previous\+\_\+output + alpha \texorpdfstring{$\ast$}{*} input 其中：
\begin{DoxyItemize}
\item previous\+\_\+output 表示上一次滤波的输出值。
\item alpha 是平滑因子，控制滤波器的响应速度和平滑程度。
\item input 是当前输入值。
\end{DoxyItemize}

一阶低通滤波器初始化函数。 

此函数用于初始化一阶低通滤波器的参数，设置滤波器的平滑因子（alpha）以及初始输出值。 平滑因子 alpha 的取值范围通常在 (0, 1\mbox{]} 之间：
\begin{DoxyItemize}
\item 当 alpha 接近 1 时，滤波器对输入信号的变化更敏感，响应更快，但滤波效果较弱。
\item 当 alpha 接近 0 时，滤波器对输入信号的变化反应较慢，但滤波效果更强。
\end{DoxyItemize}
