重置四元数扩展卡尔曼滤波器（\+QEKF）的状态和参数。 

此函数用于将\+QEKF的状态和参数恢复到初始状态，适用于滤波器发散或需要重新初始化的情况。 主要操作包括：
\begin{DoxyEnumerate}
\item 调用通用的\+Kalman\+\_\+\+Filter\+\_\+\+Reset函数重置卡尔曼滤波器的核心矩阵。
\item 恢复协方差矩阵\+P到其初始值。
\item 初始化姿态四元数为单位四元数（表示零姿态）。
\item 设置标志位以跳过标准卡尔曼滤波步骤中的增益计算（\+Set\+K）和后验估计更新（xhat\+Update），改用自定义实现。
\item 恢复状态转移矩阵\+F和协方差矩阵\+P的初始值。 
\end{DoxyEnumerate}\Hypertarget{_quaternion_e_k_f_8h_ae323af11f1e78bd5438e27fb7cb494f1}\index{QuaternionEKF.h@{QuaternionEKF.h}!IMU\_QuaternionEKF\_Update@{IMU\_QuaternionEKF\_Update}}
