◆ send_robot_state()

void send_robot_state ( )

发送机器人状态数据包

注解
数据包结构：
  • 包头：0x5A（固定标识）
  • 颜色检测：0=未检测颜色模式
  • 跟踪重置：0=保持当前跟踪状态
  • 预留字段：保留未来扩展
  • 姿态数据：当前偏航/俯仰角度
  • 目标坐标：归一化后的三维坐标
  • 自动添加CRC16校验
