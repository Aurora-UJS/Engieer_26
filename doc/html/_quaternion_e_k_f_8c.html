◆ IMU_QuaternionEKF_Reset()

void IMU_QuaternionEKF_Reset ( void )

重置四元数扩展卡尔曼滤波器（QEKF）的状态和参数。

此函数用于将QEKF的状态和参数恢复到初始状态，适用于滤波器发散或需要重新初始化的情况。 主要操作包括：

  1. 调用通用的Kalman_Filter_Reset函数重置卡尔曼滤波器的核心矩阵。
  2. 恢复协方差矩阵P到其初始值。
  3. 初始化姿态四元数为单位四元数（表示零姿态）。
  4. 设置标志位以跳过标准卡尔曼滤波步骤中的增益计算（SetK）和后验估计更新（xhatUpdate），改用自定义实现。
  5. 恢复状态转移矩阵F和协方差矩阵P的初始值。
